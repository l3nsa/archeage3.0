## Настройка клиента

### Конфигурация подключения

Для подключения к серверу необходимо настроить IP-адрес и порт Login-сервера в конфигурационном файле клиента.

1. Найдите файл конфигурации клиента (`system.cfg` или аналогичный) в корневой директории установленного клиента
2. Откройте файл в текстовом редакторе
3. Укажите IP-адрес и порт Login-сервера

### Основные параметры

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| IP-адрес Login-сервера | `127.0.0.1` | Адрес сервера авторизации |
| Порт Login-сервера | `1237` | Порт для подключения клиента |

### Примеры настройки

**Локальная игра (сервер на этом же компьютере):**
```
login_ip = 127.0.0.1
login_port = 1237
```

**Игра по локальной сети (LAN):**
```
login_ip = 192.168.1.100
login_port = 1237
```
> Где `192.168.1.100` — IP-адрес компьютера с запущенным сервером в вашей локальной сети.

**Игра через интернет:**
```
login_ip = <внешний_IP_сервера>
login_port = 1237
```

## Процесс подключения

### Пошаговая инструкция

#### Шаг 1: Запуск Login-сервера

Запустите Login-сервер (`AAEmu.Login`). Дождитесь сообщения об успешной инициализации в консоли.

```
LoginServer started on port 1237
InternalNetwork listening on port 1234
```

#### Шаг 2: Запуск Game-сервера

Запустите Game-сервер (`AAEmu.Game`). **Обязательно** дождитесь полной загрузки всех менеджеров:

```
WorldManager initialized
SkillManager initialized
ItemManager initialized
QuestManager initialized
HousingManager initialized
SaveManager started (interval: 5 min)
...
GameServer started on port 1239
```

> **Внимание:** не подключайтесь к серверу, пока все менеджеры не загружены. Преждевременное подключение может привести к ошибкам или вылетам.

#### Шаг 3: Запуск клиента ArcheAge

Запустите клиент ArcheAge версии 3.0.3.0.

#### Шаг 4: Авторизация

- Введите **имя аккаунта** в поле логина
- Введите **пароль** (если `AutoAccount` выключен в конфигурации сервера)
- Если `AutoAccount = true`: при первом входе аккаунт создастся автоматически с любым введённым именем

#### Шаг 5: Выбор сервера

- После успешной авторизации отобразится список доступных игровых серверов
- Выберите нужный сервер из списка

#### Шаг 6: Создание или выбор персонажа

- Если это первый вход — создайте нового персонажа
- Имя персонажа должно соответствовать правилам (по умолчанию: буквы латиницы, кириллицы и цифры, от 1 до 18 символов)
- Если персонаж уже существует — выберите его из списка

#### Шаг 7: Вход в мир

- Нажмите кнопку входа в игру
- Клиент подключится к Game-серверу и загрузит игровой мир
- Первая загрузка может быть длительной, если включена настройка `HeightMapsEnable`

## Схема аутентификации

### Диаграмма обмена пакетами

```
Клиент                    Login-сервер                Game-сервер
  │                            │                           │
  │  ①  CARequestAuthPacket    │                           │
  │  (логин, пароль, MAC, CPU) │                           │
  │ ─────────────────────────> │                           │
  │                            │                           │
  │  ②  ACAuthResponsePacket   │                           │
  │  (ID аккаунта, токен WSK)  │                           │
  │ <───────────────────────── │                           │
  │                            │                           │
  │  ③  CAListWorldPacket      │                           │
  │  (запрос списка серверов)  │                           │
  │ ─────────────────────────> │                           │
  │                            │  ④  LGRequestInfoPacket   │
  │                            │  (запрос статуса)         │
  │                            │ ────────────────────────> │
  │                            │                           │
  │                            │  ⑤  GLRegisteredPacket    │
  │                            │  (статус, онлайн)         │
  │                            │ <──────────────────────── │
  │                            │                           │
  │  ⑥  ACWorldListPacket      │                           │
  │  (список серверов)         │                           │
  │ <───────────────────────── │                           │
  │                            │                           │
  │  ⑦  CAEnterWorldPacket     │                           │
  │  (выбор сервера)           │                           │
  │ ─────────────────────────> │                           │
  │                            │  ⑧  LGPlayerEnterPacket   │
  │                            │  (данные игрока)          │
  │                            │ ────────────────────────> │
  │                            │                           │
  │  ⑨  ACWorldCookiePacket    │                           │
  │  (куки сессии)             │                           │
  │ <───────────────────────── │                           │
  │                            │                           │
  │ ═══════════ TCP-подключение к Game-серверу (порт 1239) ═══════>│
  │                            │                           │
  │  ⑩  CSEnterWorldPacket                                 │
  │  (куки, выбор персонажа)                               │
  │ ─────────────────────────────────────────────────────> │
  │                            │                           │
  │  ⑪  SCInitialConfigPacket                              │
  │  (начальная конфигурация)                              │
  │ <───────────────────────────────────────────────────── │
  │                            │                           │
```

### Описание этапов

| Этап | Пакет | Описание |
|------|-------|----------|
| ① | `CARequestAuthPacket` | Клиент отправляет данные авторизации (логин, информация о системе) |
| ② | `ACAuthResponsePacket` | Login-сервер подтверждает авторизацию, выдаёт токен сессии (WSK) |
| ③ | `CAListWorldPacket` | Клиент запрашивает список доступных игровых серверов |
| ④ | `LGRequestInfoPacket` | Login-сервер запрашивает у Game-сервера актуальную информацию |
| ⑤ | `GLRegisteredPacket` | Game-сервер отвечает Login-серверу: статус, количество онлайн-игроков |
| ⑥ | `ACWorldListPacket` | Login-сервер отправляет клиенту список серверов с информацией |
| ⑦ | `CAEnterWorldPacket` | Клиент выбирает сервер для входа |
| ⑧ | `LGPlayerEnterPacket` | Login-сервер уведомляет Game-сервер о входящем игроке |
| ⑨ | `ACWorldCookiePacket` | Login-сервер отправляет клиенту куки для подключения к Game-серверу |
| ⑩ | `CSEnterWorldPacket` | Клиент подключается к Game-серверу напрямую по TCP (порт 1239) |
| ⑪ | `SCInitialConfigPacket` | Game-сервер отправляет начальную конфигурацию мира клиенту |

### Важные замечания

- **Два TCP-соединения:** клиент сначала подключается к Login-серверу (порт 1237), затем отдельным соединением к Game-серверу (порт 1239)
- **SecretKey:** используется для верификации связи между Login- и Game-серверами. Должен совпадать в обоих конфигурационных файлах
- **WSK (Web Session Key):** уникальный токен сессии, привязывающий авторизацию к подключению

## Устранение неполадок

### Ошибки подключения

| Проблема | Возможная причина | Решение |
|----------|------------------|---------|
| **«Connection refused»** (Отказ в соединении) | Сервер не запущен или указан неверный IP/порт | Убедитесь, что Login-сервер запущен и прослушивает порт 1237. Проверьте IP-адрес в настройках клиента |
| **Пустой список серверов** | Game-сервер не подключён к Login-серверу | Проверьте, что Game-сервер запущен и `LoginNetwork` настроен корректно (порт 1234). Проверьте логи обоих серверов |
| **«Enter world denied»** (Вход запрещён) | Ошибка создания персонажа или сервер переполнен | Проверьте логи Game-сервера. Убедитесь, что база данных доступна и таблица `characters` существует |
| **Разрыв соединения** | Ошибка на стороне сервера | Проверьте `Logs/Error.log` на обоих серверах для выявления причины |
| **Вылет клиента** | Несовместимая версия клиента | Убедитесь, что используется клиент версии 3.0.3.0. Другие версии не поддерживаются |
| **Долгая загрузка** | Загрузка карт высот | Параметр `HeightMapsEnable` в конфигурации Game-сервера вызывает задержку при первой загрузке. Это нормальное поведение |

### Диагностика через логи

**Login-сервер (`AAEmu.Login/Logs/`):**
```
# Успешная авторизация
[INFO] LoginServer - Account 'player1' authenticated successfully

# Ошибка подключения Game-сервера
[ERROR] InternalNetwork - Cannot connect to GameServer at 127.0.0.1:1234
```

**Game-сервер (`AAEmu.Game/Logs/`):**
```
# Успешное подключение к Login-серверу
[INFO] LoginNetwork - Connected to LoginServer at 127.0.0.1:1234

# Ошибка базы данных
[ERROR] MySQL - Access denied for user 'root'@'localhost'
```

### Контрольный список при проблемах

1. ✅ Login-сервер запущен и показывает сообщение о прослушивании порта 1237
2. ✅ Game-сервер запущен, все менеджеры загружены, порт 1239 активен
3. ✅ Game-сервер подключился к Login-серверу (внутренний порт 1234)
4. ✅ MySQL запущен и доступен на порту 3306
5. ✅ Базы данных `aaemu_login` и `aaemu_game` созданы и заполнены
6. ✅ `SecretKey` совпадает в обоих конфигурационных файлах
7. ✅ IP-адрес в настройках клиента соответствует адресу Login-сервера
8. ✅ Файрвол не блокирует порты 1237 и 1239

## Сетевые требования

### Порты

| Порт | Протокол | Служба | Доступность |
|------|----------|--------|-------------|
| **1237** | TCP | Login-сервер | Должен быть доступен для клиентов |
| **1239** | TCP | Game-сервер | Должен быть доступен для клиентов |
| **1250** | TCP | Stream-сервер | Должен быть доступен для клиентов |
| **1234** | TCP | Внутренняя связь | Только localhost (Login ↔ Game) |
| **3306** | TCP | MySQL | Только localhost |

### Локальная игра (один компьютер)

Сервер и клиент запускаются на одном компьютере. Дополнительная настройка сети не требуется.

**Конфигурация серверов:**
- Login-сервер `Network.Host`: `*` или `127.0.0.1`
- Game-сервер `Network.Host`: `127.0.0.1`

**Конфигурация клиента:**
```
login_ip = 127.0.0.1
login_port = 1237
```

### Игра по локальной сети (LAN)

Несколько компьютеров в одной сети подключаются к серверу.

**Конфигурация серверов:**

1. Login-сервер (`Config.json`):
   ```json
   {
       "Network": {
           "Host": "192.168.1.100",
           "Port": 1237
       }
   }
   ```

2. Game-сервер (`Config.json`):
   ```json
   {
       "Network": {
           "Host": "192.168.1.100",
           "Port": 1239
       }
   }
   ```

3. Также обновите запись в таблице `game_servers` базы данных `aaemu_login`:
   ```sql
   UPDATE game_servers SET host = '192.168.1.100' WHERE id = 1;
   ```

**Конфигурация клиента (на других компьютерах):**
```
login_ip = 192.168.1.100
login_port = 1237
```

> Замените `192.168.1.100` на фактический IP-адрес сервера в локальной сети.

### Игра через интернет

Сервер доступен из интернета для удалённых игроков.

**Дополнительные шаги:**

1. **Проброс портов (Port Forwarding):** настройте на роутере проброс портов:
   - Порт `1237` (TCP) → IP сервера в локальной сети
   - Порт `1239` (TCP) → IP сервера в локальной сети

2. **Файрвол:** добавьте исключения для портов 1237 и 1239:
   ```bash
   sudo ufw allow 1237/tcp
   sudo ufw allow 1239/tcp
   ```

3. **Конфигурация серверов:** укажите локальный IP-адрес (не `127.0.0.1`)

4. **Обновите базу данных:** запись `game_servers` должна содержать внешний IP или IP, доступный клиентам

5. **Конфигурация клиента:** укажите внешний IP-адрес сервера
   ```
   login_ip = <внешний_IP_сервера>
   login_port = 1237
   ```

> **Безопасность:** при открытии сервера в интернет обязательно измените `SecretKey`, отключите `AutoAccount`, используйте надёжные пароли MySQL. Подробнее — в разделе безопасности [руководства по администрированию](ADMINISTRATION.md#безопасность).

## Несколько клиентов и аккаунтов

### Автоматическое создание аккаунтов

Если в конфигурации Login-сервера установлено `AutoAccount: true`:

- При первом входе с новым именем пользователя аккаунт создаётся автоматически
- Пароль задаётся при первом входе и сохраняется в базе данных
- Это удобно для тестирования, но **небезопасно для публичных серверов**

### Множественные подключения

- Несколько клиентов могут подключаться к серверу одновременно
- Каждый аккаунт может иметь персонажей на каждом игровом сервере
- Ограничение одновременных подключений задаётся параметром `NumConnections` в конфигурации

### Управление аккаунтами

Аккаунты хранятся в таблице `users` базы данных `aaemu_login`:

```sql
-- Просмотр всех аккаунтов
SELECT * FROM users;

-- Изменение уровня доступа (сделать администратором)
UPDATE users SET access_level = 100 WHERE username = 'admin';

-- Блокировка аккаунта
-- (реализуется через установку соответствующего поля в базе данных)
```

### Уровни доступа аккаунтов

| Уровень | Роль | Описание |
|---------|------|----------|
| 0 | Игрок | Стандартный доступ, базовые команды |
| 50 | Модератор | Управление игроками, спавн, модерация |
| 100 | Администратор | Полный доступ ко всем командам и настройкам |

> Подробное описание команд каждого уровня доступа — в [руководстве по администрированию](ADMINISTRATION.md#gm-команды).
