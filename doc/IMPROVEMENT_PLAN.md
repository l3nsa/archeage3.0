## 2. Что можно переиспользовать из AAEmu v1.2

> Справочный репозиторий: [AAEmu/AAEmu](https://github.com/AAEmu/AAEmu) (develop, 394 ⭐, 247 форков)

### Сравнительная таблица

| Компонент | archeage3.0 (текущий) | AAEmu v1.2 (справочный) | Статус |
|-----------|----------------------|------------------------|--------|
| **.NET версия** | 2.2 (устаревший) | 10.0 (актуальный) | ❌ Критично |
| **Менеджеры** | ~39 базовых | 56 специализированных | ⚠️ Отстаёт |
| **Юнит-тесты** | Нет | TUnit + xUnit + Moq + Testcontainers | ❌ Нет |
| **Docker** | Нет | docker-compose + Dockerfile | ❌ Нет |
| **Скрипты сборки** | 3 bat-файла | 12+ скриптов (Win/Linux) | ⚠️ Минимально |
| **Документация** | Только скриншоты | TestingPlan, WorldConfig (RU/EN) | ❌ Нет |
| **Пакеты NuGet** | Базовый набор | 40+ с центральным управлением | ⚠️ Отстаёт |
| **Lua-скрипты** | Нет | NLua интеграция | ❌ Нет |
| **Discord-бот** | Нет | Discord.Net интеграция | ❌ Нет |
| **2FA** | Нет | OTP.NET | ❌ Нет |
| **Телеметрия** | Нет | OpenTelemetry | ❌ Нет |
| **CI/CD** | Travis (устаревший) | GitHub Actions | ⚠️ Устаревший |

### Конкретные компоненты для переиспользования

#### 🟢 Прямое копирование (адаптация путей)

1. **Docker-инфраструктура**
   - `docker-compose.yaml` — оркестрация MySQL + Adminer + Login + Game серверов
   - `AAEmu.Game/Dockerfile`, `AAEmu.Login/Dockerfile`
   - Скрипты: `docker-install-local.sh`, `docker-update-local.sh`

2. **Скрипты сборки и запуска**
   - `Scripts/BuildGameServer.bat`, `Scripts/BuildLoginServer.bat`
   - `Scripts/start_game.sh`, `Scripts/start_login.sh`
   - `Scripts/WatchGameServer.ps1`, `Scripts/WatchLoginServer.ps1` (hot-reload при разработке)

3. **Документация**
   - `Docs/TestingPlan_ru.md` — план тестирования на русском
   - `Docs/WorldConfig_ru.md` — руководство по настройке мира
   - `Docs/TestingProgress_ru.md` — прогресс тестирования

#### 🟡 Частичная адаптация (требуется модификация)

4. **Тестовая инфраструктура**
   - `AAEmu.UnitTests/` — базовые классы: `TestBase.cs`, `SqliteTestBase.cs`
   - Паттерн `IntegrationTestBase` — интеграционное тестирование с Testcontainers
   - NuGet-пакеты: TUnit, Moq, Testcontainers.MySql

5. **Недостающие менеджеры** (адаптация логики v1.2 → v3.0)
   - `PublicFarmManager` — общественные фермы
   - `FishSchoolManager` — механика рыбалки
   - `CrimeManager` / `SusManager` — система преступлений и кармы
   - `IndunManager` — инстансовые подземелья
   - `InstantGameManager` — мини-игры/арены
   - `TimedRewardsManager` — награды за вход/время
   - `TaxationsManager` — налоговая система
   - `MusicManager` — аудио-система
   - `RadarManager` — радар/мини-карта
   - `GameScheduleManager` — расписание событий
   - `FeaturesManager` — флаги функций
   - `ExpressTextManager` — быстрые сообщения
   - `AiGeodataManager` — геоданные для ИИ
   - `AiPathsManager` — пути для ИИ NPC
   - `ManaRegenManager` — регенерация маны
   - `SubZoneManager` — управление подзонами
   - `ModelManager` — 3D-модели

6. **Архитектура пакетов NuGet**
   - `Directory.Build.props` — централизованная конфигурация сборки
   - `Directory.Packages.props` — центральное управление версиями пакетов

7. **Утилиты и инструменты**
   - `Tools/WorldConverter` — конвертация форматов мира
   - `Tools/UpdatesForTransform` — утилита миграции данных

#### 🔵 Долгосрочная модернизация

8. **Обновление фреймворка**
   - Миграция с .NET Core 2.2 → .NET 8.0 LTS (минимум) или .NET 10.0
   - Переход на `Microsoft.Extensions.DependencyInjection`
   - Переход на `Microsoft.Extensions.Hosting`

9. **Интеграции**
   - NLua — Lua-скрипты для игровой логики
   - Discord.Net — бот для управления сервером
   - OTP.NET — двухфакторная аутентификация
   - OpenTelemetry — мониторинг и трассировка

10. **CI/CD**
    - Миграция с Travis CI → GitHub Actions
    - Автоматическая сборка, тестирование и деплой
